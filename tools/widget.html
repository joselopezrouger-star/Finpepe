Widget de FinPep

Tu saldo del mes, cuánto podés gastar por día y un botón para cargar un gasto, en la pantalla de inicio del iPhone.

  1. Instalá Scriptable (gratis) desde la App Store.
  2. Tocá Copiar el script acá abajo.
  3. Abrí Scriptable, tocá + arriba a la derecha, pegá el script y ponele de nombre FinPep (tocando el título de arriba).
  4. Tocá ▶︎ abajo a la derecha: te pide tu usuario y contraseña de FinPep (quedan guardados solo en tu iPhone) y te muestra el widget. Si entrás con Google, primero creá una contraseña en FinPep › Ajustes › Cuenta › Crear contraseña: ahí te dice con qué entrar.
  5. En la pantalla de inicio, mantené apretado un espacio vacío → Editar → Agregar widget → Scriptable → elegí el tamaño mediano o el chico → Agregar widget.
  6. Mantené apretado el widget → Editar widget → en Script elegí FinPep.

Ver el script

Tocar el saldo abre FinPep y tocar + Gasto abre el formulario de nuevo gasto (en el widget chico, todo el widget abre el formulario). Se actualiza solo cada 15 a 30 minutos, cuando iOS lo decide. Para cambiar de cuenta, abrí el script en Scriptable y tocá ▶︎.
